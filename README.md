# AI Harness Homebrew tap

Install AI Harness CLI on an Apple Silicon Mac:

```bash
brew install bhumirath/ai-harness/harness
```

Upgrade later with:

```bash
brew update
brew upgrade harness
```

The formula downloads the public, checksum-verified standalone binary from
[`ai-harness-cli-project`](https://github.com/bhumirath/ai-harness-cli-project/releases).

Current support: macOS Apple Silicon (M1 or newer).
